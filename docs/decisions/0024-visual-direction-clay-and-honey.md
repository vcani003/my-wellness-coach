# 0024 — Visual direction: Clay & Honey

**Status:** Accepted · 2026-10-14 · Decided by Vero (V1, V2)

- **Direction C, "Clay & Honey"**: cosy and rounded, like an afternoon with tea in a hand-thrown mug. Cream surfaces, a clay accent, pill-shaped buttons, and Nunito throughout. Tokens and contrast tables are in [visual-direction.md](../design/visual-direction.md) under C.
- **Plum is used only for allergy flags (V2)**, so it always means "allergy", and it's unmistakable without looking alarming.
- Frontend implements C's **semantic tokens** only (0017). All of C's pairs pass WCAG AA; don't lighten the control borders.
