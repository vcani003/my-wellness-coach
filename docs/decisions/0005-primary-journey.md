# 0005 — The primary MVP journey

**Status:** Accepted · 2026-10-13 · Decided by Vero

## Decision
The Epic (spec §10) is judged on this journey:

1. "I bought eggs, chicken thighs, spinach and yogurt." → the Kitchen widget appears with those items.
2. "I froze the chicken." → the Kitchen widget updates and the chicken moves to the freezer.
3. "What can I make tonight?" → the Meal ideas widget appears.
4. **The user clearly selects one meal.**
5. "Add that to my meal plan." → the Meal plan widget shows the selected meal.
6. Close the app and come back later. Everything is still there.

## Note on step 4
"Add that" must refer to a meal the user explicitly picked, never one the assistant guessed. *How* the user selects (tapping the meal, saying which one, or both) is still open.
