# 0050: Bright look details

**Status:** Accepted · 2026-10-16 · Decided by Vero (BRT1–BRT3, all Recs). Refines [0048](0048-bright-look.md).

- **BRT1. Main buttons keep dark ink text on the coral gradient** (5.58:1, passes AA). White text on coral fails (2.55:1). This keeps the prototype's colours; darker brick-red buttons were the alternative.
- **BRT2. The allergy-only colour (KOS15) is berry**, not plum, because plum looked too close to the lavender freezer tint.
- **BRT3. The "What changed" box is soft mint**, so it reads as "saved".
