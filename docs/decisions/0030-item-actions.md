# 0030 — Actions on kitchen items, and Counter as a place

**Status:** Accepted · 2026-10-15 · Decided by Vero (IA1). Replaces "See all is view-only" (K1, 0017).

- Each item row (Kitchen widget and See all) has a **⋯ menu**: **Used up / Out · Running low · Move to… · Change type… · Edit name / amount · Remove (added by mistake)**. It opens by tap, **right-click** on desktop, or **long-press** on phone.
- **On phone, also swipe left → Remove.** There's no standalone ✕, because it's too easy to tap by accident.
- Every action goes through the same validate → apply path as chat, shows **"What changed" with Undo**, and is recorded in history. Remove asks once ("Remove fish sauce? It'll stay in history.").
- **Counter** joins Fridge / Freezer / Pantry / Not sure where as a place. "Defrosting on the counter" now keeps it there (DF1).
