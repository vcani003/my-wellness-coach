# 0008 — Meal plan is a short upcoming list

**Status:** Accepted · 2026-10-13 · Decided by Vero

## Decision
In MVP 1 the meal plan is a short, ordered list of meals the user intends to make. It has no dates, slots or calendar.

## Ingredients
- **No reserving:** adding a meal to the plan does not set its ingredients aside (Vero, 2026-10-13).
- **Open:** whether "I made it" marks ingredients as used (see OPEN-QUESTIONS M2).
