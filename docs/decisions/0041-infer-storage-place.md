# 0041 — Kitchen infers where things go

**Status:** Accepted · 2026-10-15 · Decided by Vero. Changes 0011's "storage location stays unknown unless said".

- **When you add an item, Kitchen puts it where it usually goes:** milk to the Fridge, rice to the Pantry, frozen peas to the Freezer. You don't have to say where.
- The place is recorded as **inferred** (provenance kept). If you say where, that wins.
- **Corrections are remembered** per kitchen ("onions go in the pantry"), the same way item types are (0032).
- **Items already in "Not sure where"** are sorted once, automatically, as one change with "What changed" and **Undo** (Rec).
- **"Not sure where" stays** only for things that genuinely can't be placed.
- Counter becomes a choice when Epic A's Counter place ships (0030). Until then, the choices are Fridge, Freezer and Pantry.
