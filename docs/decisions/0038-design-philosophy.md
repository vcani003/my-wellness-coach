# 0038 — Design philosophy

**Status:** Accepted · 2026-10-15 · Set by Vero. Lives in [design/visual-direction.md](../design/visual-direction.md).

1. If it looks boring, adjust the layout.
2. No focal point? Use contrast.
3. If it doesn't stand out, exaggerate the scale.
4. If it feels plain, add more details.

UX runs these checks in every design review, and Frontend before each screen ships. They apply from B3 (the design system) onward, including the option 2 layout (0034).
