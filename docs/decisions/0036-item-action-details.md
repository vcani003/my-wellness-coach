# 0036 — Item action details

**Status:** Accepted · 2026-10-15 · Decided by Vero (IA2–IA6, all Recs). Details for 0030; spec `docs/design/item-actions.md`.

- **IA2:** "Used up / Out" on an item with several batches marks the **whole item** out. To close one batch, say so in chat ("the old eggs are gone").
- **IA3:** actions taken from the Kitchen list **don't appear in chat**. The "What changed" receipt shows where you acted, and history records the change.
- **IA4:** "Edit amount" on an item with several batches changes the **oldest open batch**.
- **IA5:** moving an item out of the Freezer from the menu **counts as defrosting** and sets "Defrosted on".
- **IA6:** a rename gets its own receipt line ("Renamed fish sauce → nước mắm"). This is a small follow-up after Epic A.
