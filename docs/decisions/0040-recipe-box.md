# 0040 — Finding and cooking past recipes

**Status:** Accepted · 2026-10-15 · Decided by Vero (RB1–RB9, all Recs). Plan: [plans/recipe-box.md](../plans/recipe-box.md).

- **"Cooked before"** lists only meals marked Done (RB1). Each meal's recipe is the version that was cooked (RB2). The same dish cooked twice is one row, "made 2×, last 15 Oct", which opens the latest (RB3).
- **Search** matches name and ingredient (RB9). No renaming (RB4) and no favourites (RB6) in MVP.
- **Kitchen-wide:** household members see each other's past recipes, with who cooked each one (RB5).
- **Make again** copies the cooked version into a new meal, refinable as usual; the original is never changed.
- **Chat:** naming a dish you've made asks once, "The one from 15 Oct, or a new one?", with the past one first (RB7). This changes 0013 MI1 only when a matching past meal exists.
- **Allergies:** an old recipe that now clashes with someone's allergy is allowed, always flagged, and gets a one-tap "make it without X" (RB8, 0019).
